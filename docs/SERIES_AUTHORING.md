# Series Authoring

## Add a new series

1. Create `series/<slug>/series.json`  
2. Add `BIBLE.md` + `bible/` machine packs  
3. Add `characters/`, `locations/`, `props/` with JSON locks  
4. Register canonical assets in `references/canonical_index.json`  
5. Add `seasons/` and `episodes/<id>/{brief,script,storyboard}.json`  

Do **not** hard-code the core engine to Likkle Jay. Likkle Jay is the first configuration.

## Comedy structure

SETUP → TEMPTATION/MISUNDERSTANDING → ESCALATION → DISCOVERY → REACTION → PUNCHLINE

## Engagement

Plan for strong opening, clear premise, fast setup, escalation, reaction, recognisable behaviour, visual comedy, strong final beat — without breaking canon.
